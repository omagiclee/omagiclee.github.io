# 复刻验收清单

逐项保留可核对证据。静态首屏相似不足以通过；动作、刷新、错误、权限和移动端状态也应一致。已有用例索引见 [TEST_CASES.md](verification/TEST_CASES.md)。

## 1 外壳与路由

- [ ] 1440px 桌面侧栏、顶部行、白色内容区、字体、主色与截图一致。
- [ ] 两个规范项目路由和两个旧兼容路由均可进入。
- [ ] 刷新保留流程、Tab、运行、版本或插件 release 的 URL 上下文。
- [ ] 切项目或账号不会串用列表、权限、运行或插件草稿。
- [ ] 无读权限显示申请入口；无编辑权限仍可查看。
- [ ] 390px 下使用导航和参数抽屉；Escape、关闭与焦点返回可用。

## 2 流水线目录与新建

- [ ] 搜索名称/说明、状态筛选、20 条分页和返回列表恢复条件正常。
- [ ] 加载、请求失败重试、首次空列表、无匹配、后续空页分别正确。
- [ ] 空白流程、七节点视频模板、两节点文本模板均进入相应编排。
- [ ] 视频模板不自动运行；文本模板按准确已启用版本创建。
- [ ] 算子卡片跳转只预填指定版本一次；缺少该版本报错。

## 3 编排

- [ ] 新增使用 default_config、唯一 node ID；选中兼容上游时自动连接。
- [ ] 未选上游或 sink 不会被当成默认上游；多输入只连接一个兼容端口。
- [ ] 拖线和上游下拉共用校验，拒绝自连接、循环、错类型、错误端口及 sink 下游。
- [ ] 具名端口分别保存；替换一个端口不破坏另一个端口。
- [ ] 删除节点清除依赖边；删除边不删节点；Delete/Backspace 可用。
- [ ] 移动位置可保存刷新恢复；一次拖动一次撤销；自动布局和缩略图可用。
- [ ] 放大、缩小、适配和缩放边界一致；只读运行图不能修改。
- [ ] 撤销、重做和快捷键保留图配置及连接，在输入区不劫持文本撤销。
- [ ] 宽屏可显示三列，紧凑区优先参数，窄屏使用抽屉。

## 4 参数与保存

- [ ] number/integer/boolean/enum/JSON 控件保持原 JSON 类型。
- [ ] 本地 ref、allOf、nullable 和复杂配置 JSON 路径可用。
- [ ] 无效 JSON 保留文本，切节点再回来不丢失，保存和运行禁用。
- [ ] 从无效完整 JSON 切表单需修正或明确丢弃；其他节点编辑保留。
- [ ] 顶部错误定位能打开正确节点与字段模式。
- [ ] 校验成功与错误列表来自 API；1–40 节点等规则由服务端复核。
- [ ] 未命名或无节点不能保存；已保存且没变更不能重复保存。
- [ ] 保存生成新版本；expected_version 409 不丢本地草稿。
- [ ] 干净状态自动读新版本；脏状态可选择加载最新或保留草稿基线。
- [ ] 导出 JSON 可再导入；导入大小与结构校验、替换与撤销正确。
- [ ] 名称/说明改动随版本保存；离开脏流程有保护。

## 5 运行 调试与产物

- [ ] 正式运行按钮标记实际 version；脏草稿、未知运行状态和冲突阻止提交。
- [ ] 当前版本有活动运行时进入原运行，不额外创建。
- [ ] 双击、网络错误和刷新恢复复用原 idempotency_key、目标与缓存策略。
- [ ] 不完整提交记录提示先确认，不悄悄创建新意图。
- [ ] 执行环境/池弹层按授权和可用状态展示，切环境清空池。
- [ ] 调试样本 1–100，默认 20；先预检再运行。
- [ ] 预检冻结 plan_digest；改变上下文使计划失效；旧响应不能覆盖新上下文。
- [ ] 调试 4xx 清理意图，不确定失败复用原意图；媒体不支持时明确失败。
- [ ] 运行列表按当前流程/版本过滤；其他流程 runId 不会被展示。
- [ ] 列表和详情在活动时轮询，终态停止；取消等待引擎确认。
- [ ] 恢复提交、对账和新运行三种动作保持不同语义。
- [ ] 运行图和任务表选择联动；无计划的旧运行也能检查任务。
- [ ] 进度、记录数、耗时、错误和无输出说明与真实状态一致。
- [ ] 产物预览最多 20 条，完整下载、血缘及缓存来源可用。
- [ ] 文档正式成功产物≤1000 条且有权限才可导入候选；调试与超限有解释。
- [ ] 导入显示来源及质量问题，跳到候选数据集，不直接发布。

## 6 历史与部署

- [ ] 历史版本只读，节点配置和完整图可查看，可进入该版本的运行。
- [ ] 部署区按需加载；创建冻结版本、配置、时区和资源。
- [ ] 间隔秒数范围、首次时间与节点覆写 JSON 约束正常。
- [ ] 暂停不取消已有运行；未暂停部署可手动触发；失败重试保留 event_key。
- [ ] 未擅自加入当前 UI 没有的版本比较、恢复或触发历史功能。

## 7 算子与插件

- [ ] 算子搜索、分类优先规则、模态推断及通用算子回退一致。
- [ ] 每个准确版本独立卡片；契约展开与用于新流水线链接正确。
- [ ] 启用弹窗包括已发布版本和预装插件、搜索、分页、能力展开。
- [ ] 未发布/环境未就绪/无权限不能启用；启用后目录刷新，不改旧流程。
- [ ] 开发目录按插件分组，精确 pluginId 历史、分页和搜索保持 URL 状态。
- [ ] 所选 release 不在当前页时继续显示详情并说明。
- [ ] 模板下载失败有提示；新建是全屏三段工作区。
- [ ] wheel、manifest、tests 文件限制及 12 MiB 总请求限制有效。
- [ ] identity、operators、test_cases 可导入和高级编辑；JSON 与必填错误明确。
- [ ] 上传只创建 candidate，不自动验证/发布/启用；双击不会重复创建。
- [ ] 插件文本草稿按账号项目恢复；刷新后 wheel 必须重选。
- [ ] 关闭和 Escape 有继续/保留/放弃；只在明确放弃或成功上传后清草稿。
- [ ] 五步生命周期分别取实际字段，权限和状态共同决定操作可用性。
- [ ] 验证失败、受阻、排队、运行、通过都有不同提示与刷新策略。
- [ ] 报告分通过/失败/未知；缺失值不能算通过。
- [ ] 失败预期/实际按样例名及算子 ID 配对，报告与日志分别折叠。
- [ ] release 的 wheel/runtime/SDK 摘要、时间、声明、样例及历史验证完整可查。

## 8 实现交付

- [ ] 核心组件、共享 UI、CSS 后段覆盖、字体文件和锁文件均未遗漏。
- [ ] 两页所有可见按钮有实际行为；mock 与真实执行的边界清楚标示。
- [ ] 对照截图记录视觉差异；对照原测试记录行为差异。
- [ ] 未将历史需求文章的提议写成当前已实现功能。
