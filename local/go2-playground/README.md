# Go2 强化学习游乐场

本机运行的 Unitree Go2 + MuJoCo + PPO 原型。浏览器画面来自原生 MuJoCo 渲染，控制与训练使用相同的物理环境。没有预训练策略或脚本步态。

## 启动

```bash
cd /Users/omagiclee/Desktop/omagiclee.github.io/local/go2-playground
./run.sh
```

打开 <http://127.0.0.1:8766/>。服务仅监听本机回环地址。按 `Ctrl+C` 关闭服务；进行中的界面训练会收到停止请求并保存模型。

首次重建环境使用 `./setup.sh`。它创建独立 `.venv`、安装 `requirements.txt` 中锁定的版本，并下载 `model-version.txt` 指定的 Go2 模型。需要 Python 3.12；脚本优先使用本机 Codex 随附的解释器，也可用 `GO2_PYTHON=/path/to/python3.12 ./setup.sh` 指定解释器。没有修改系统 Python、其他项目依赖或博客页面。

## 怎么玩

1. 初始进入“站姿参考”：固定关节目标经过 PD 控制转成电机力矩，观察机器狗站立。此模式不执行速度指令。
2. 用“随机动作”观察关节探索；可以暂停、重置、切换视角、施加一次 50 N / 0.1 s 的横向推力。
3. 选择训练步数和随机种子，点击“开始训练”。训练在单独进程中运行，保留实时回报曲线和日志。
4. 训练完成后，选择保存的策略，点击“加载到训练场”。此时速度滑块及 W/S 前后、A/D 转向由 PPO 策略执行。
5. 勾选“从选中策略继续训练”开始下一段训练。“停止并保存”在下一次采样后停止，保存当前模型并进行独立评估。

短训练验证学习流程，不能证明已经学会稳定行走。未训练充分的策略可能原地站立、滑动或跌倒；发生跌倒时展示场景暂停，点击重置即可继续。站姿参考控制与 PPO 始终分别标注。

## 本机实测

2026-10-13：Apple M4、10 核 CPU、16 GB 内存，arm64 / Python 3.12.14。

- 环境通过 Stable Baselines3 的 `check_env` 校验，并通过确定性重置、动作输入、力矩限幅和 20 秒站姿测试。
- 不渲染、不更新策略时：约 **5,977 环境步/秒**、59,765 物理步/秒，约 119 倍实时速度。
- 8,192 步 PPO：命令行约 **1,576 步/秒**；同时运行浏览器和实时仿真时约 **1,360 步/秒**。
- 较长的 262,144 步实验：约 **291 秒（4 分 51 秒）**，平均 **900 步/秒**。持续速度随本机其他负载变化。
- 实时画面：960 × 540，约 **22–25 FPS**。
- 已验证：界面启动真实训练、冲突训练拒绝、加载策略、速度与键盘控制、模型下载、继续训练和正常停止。320 / 390 px 布局没有横向溢出，浏览器无脚本异常。

这些是当前任务与小型网络的测量，不代表视觉输入、复杂地形或大规模并行训练的性能。PPO 使用 2 个 CPU 计算线程、4 个仿真环境；本机虽检测到 MPS 可用，本版本没有使用 GPU 训练。

262,144 步策略的独立评估：平均速度误差 0.4903 m/s，站姿参考为 0.5021 m/s；3 个测试回合均保持 6 秒没有跌倒。改善较小，仍主要保持站立，**尚未学会稳定行走**。训练闭环已验收；要提升行走能力，还需增加训练、调整探索与奖励并持续评估。

## 任务与算法

- 机器人：官方 Menagerie Go2，12 个力矩电机；保留原模型的质量、惯量、接触几何及力矩范围。
- 物理频率：500 Hz；策略频率：50 Hz。
- 动作：12 个归一化关节偏移，范围 `[-1, 1]`，乘以 0.35 rad 加到参考姿态。500 Hz PD 内环使用 Kp=35、Kd=1，按原电机力矩范围限幅。
- 观测：机体局部线速度、角速度、投影重力、关节位置偏差、关节速度、上一步动作及目标速度，共 48 维。线速度直接来自仿真状态，当前原型不是纯视觉策略。
- 训练初始关节姿态随机扰动 ±0.025 rad；速度指令 vx∈[0.2,0.7]、vy∈[-0.15,0.15] m/s，yaw∈[-0.5,0.5] rad/s。
- 奖励：速度跟踪、转向跟踪、直立和高度；惩罚垂直速度、横滚/俯仰角速度、力矩及动作变化。跌倒终止并额外扣分。
- 算法：Stable Baselines3 PPO，128×128 MLP，4 个环境，512 步 rollout、256 batch、5 个优化 epoch。采样以每批 2,048 步进行，用户预算向上取整到完整批次；停止请求可提前结束采样。
- 独立评估：种子 101、102、103，各最多 6 秒，对比同一任务分布下的 PPO 与站姿参考。报告速度误差、保持时长、回报和是否跌倒；不以训练回报代替任务能力。

## 文件与命令

```bash
# 校验环境与纯仿真速度
.venv/bin/python benchmark.py

# 无界面训练（训练本身不渲染）
.venv/bin/python train.py --steps 65536 --seed 42

# 独立 headless Chromium 验收，使用博客仓库已有的 Playwright
node smoke-browser.cjs
```

`runs/<实验编号>/` 保存 `policy.zip`、`progress.json`、`config.json`、`history.jsonl`、`evaluation.json`。界面启动的实验还保存 `train.log`。模型可以从页面下载。环境、模型资源、训练记录和验收截图均通过本目录 `.gitignore` 排除；源码及依赖锁文件保留。

`artifacts/system.json` 为硬件与环境验收记录；`artifacts/browser-acceptance.json` 为浏览器验收记录；`artifacts/desktop.png` 和 `mobile-*.png` 为界面截图。CLI 单独启动的训练不受页面的训练进程管理器管理，建议日常从界面启动。
