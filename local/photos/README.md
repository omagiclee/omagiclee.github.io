# 本地相册与旅游足迹

在本机博客中浏览 macOS「照片」图库或导出的照片文件夹。只监听 `127.0.0.1`，照片和索引保存在本机，没有照片上传、外部 AI 调用或 iCloud 下载代码。时光地图默认复用博客现有高德接口：地图 SDK 和底图瓦片需要联网，高德能够获取地图请求对应的视野范围；照片文件不发送到地图服务。

## 启动

首次安装（仅安装 Python 依赖，会联网下载软件包）：

```sh
npm run photos:setup
```

日常启动：

```sh
npm run photos
```

打开 <http://127.0.0.1:8765/local-photos/>，或在 <http://127.0.0.1:8765/> 的本地博客导航点击 **本地相册**。直接查看足迹可打开 <http://127.0.0.1:8765/local-photos/#footprints>。`Ctrl+C` 停止服务。

默认读取 `~/Pictures/Photos Library.photoslibrary`。也可以指定其他图库或照片文件夹：

```sh
npm run photos -- --library '/完整路径/Photos Library.photoslibrary'
npm run photos -- --folder '/完整路径/旅行照片'
npm run photos -- --port 8766
npm run photos -- --offline-map
```

需要 Python 3.10–3.14。启动脚本会优先使用已安装的版本或 Codex 的 Python 3.12 运行时；可通过 `LOCAL_PHOTOS_PYTHON` 指定安装依赖时使用的解释器。

## 整理与浏览

- 读取拍摄时间、文件名、已有相册、收藏、关键词和 GPS。普通文件夹照片缺少拍摄时间时回退到文件修改时间，并明确标示。
- 按月份、相册和本地可用性浏览，搜索文件名、标签和笔记。
- 添加本地收藏、自定义相册、标签和笔记，保存在独立索引。**不会修改 Apple Photos 的收藏、相册或原文件。**
- iCloud 优化存储的项目区分「本地原图」「仅有本地预览」「尚无本地预览」。需要原图时先在 Apple Photos 中下载，再刷新索引。
- 默认排除图库中的隐藏照片和最近删除项目。第一版只索引静态照片；Live Photo 按静态画面浏览，视频不进入此索引。
- **检查重复照片** 使用文件大小预筛选和 SHA-256 比较本地原图。只标记完全相同的文件，不移动或删除。云端原图未下载时不会被检查；本地预览不能证明原图完全重复。

## 旅游足迹

主要地图入口改为 **旅游足迹**：从本机照片图库已有的城市、省份和国家信息汇总拍摄城市，显示城市数、国家或地区数以及对应照片数。这里只表示在该城市拍过照片，生活城市也会计入，不推断每次拍摄都是旅游。

- 高德行政区查询只读取公开的城市边界，以填色点亮拍摄城市。不逐张上传精确坐标，也不调用在线反向地理编码。
- 点击城市列表、已点亮区域，查看该城市照片、拍摄天数、最早及最近的拍摄日期。
- 可以按年份、国家或地区筛选，搜索城市或省份。
- **整理成旅行相册** 会按该城市和选定日期筛选照片，不把同期在其他城市拍摄的照片混入。
- 有 GPS 但缺少明确城市、以及没有 GPS 的照片分别统计，保留在全部照片中，不凭猜测点亮城市。普通导出文件夹照片通常只有 GPS，缺少系统图库的城市标签，因此可能不会自动计入足迹。
- 地图只绘制城市区域填色，不添加定位圆点。未能取得边界的城市仍保留在列表中并注明；离线模式只绘制当前页面已缓存的真实城市边界，不用圆点或圆形区域代替。
- 界面、表单、状态、日期和离线故事文案均为中文；已有文件名、相册名称及用户笔记保留原文。

城市边界保存在浏览器本地 IndexedDB，缓存有效期为 30 天。刷新、切换年份时优先批量恢复已有区域；仅缺失的边界走最多 4 个并发查询，并限制请求启动速度。缓存只有公开行政区边界，不含照片、精确拍摄坐标或高德密钥。

## 内容整理、清理复核与文搜图

进入 **内容整理**，运行本地整理任务。分开保存两条分类轴：

- 类型：截图、实拍照片、图片素材、待确认。
- 内容：发票／票据、商品／电商、订单／支付、证件／凭证、聊天／社交、文章／资料、软件界面、人物、风景、美食、宠物、建筑、海报、趣图等。

系统图库的截图标记优先于模型判断。内容分类使用离线 SigLIP2 图文模型和 macOS Vision OCR；分类是建议，可以在照片详情中修正，再用自定义标签补充。模型相似度不是概率，建议不明确的内容仍需人工复核。

清理操作只有 **待复核、保留、待删除** 三种本地标记。选择当前页可以批量复核；**没有删除、移动或写入原图的接口**。人工修正和复核状态与自动结果分开保存，重新分析不会覆盖它们。

搜索支持：

- **文字／标签检索**：搜索文件名、相册、标签、笔记和 OCR 识别文字。
- **语义文搜图**：将查询编码为同一模型空间的向量，在已建库且符合筛选条件的照片中排序，并结合 OCR 文字匹配。
- 文搜商品可先选择 **商品／电商**，再输入颜色、物品描述或品牌、型号等文字。

图像向量按模型 revision、预处理与维度区分，模型更新后需要重建对应向量，不混合不同空间。当前本项目模型为 `google/siglip2-base-patch16-224`，使用 768 维归一化向量。优先使用 `.local-photos/models/manifest.json` 中的本地轻量模型；没有本项目模型时可复用相邻 data-flywheel 项目的已安装模型与 `.venv-media`。可用 `LOCAL_PHOTOS_MODEL_ROOT` 和 `LOCAL_PHOTOS_ML_PYTHON` 指定已有本地路径。推理强制离线、禁止远程模型代码，不自动下载图库原图。模型切换时可复用同一照片的已有 OCR，不重复识别文字。

**网站前端仍是静态 HTML/CSS/JS**。本机 Python 服务读取图库并维护 `.local-photos/state/catalog.sqlite`：`photos` 保存图库索引，`analysis` 保存分类和 OCR，`vectors` 保存向量，`annotations` 保存人工修正和复核。SQLite 是一个本地文件，无需部署 PostgreSQL 或独立向量数据库。原图不存入这套数据库，数据库丢失时可以重建自动索引；备份时应另保留人工整理记录。

## 旅行相册

进入 **旅行相册**，创建一个指定日期范围的相册，可进一步按已有相册筛选，并写旅行简介。自动建议的照片组仅依据拍摄时间间隔和位置跳变，**不代表系统已经确定你去旅行**。

- 默认使用高德街道底图，复用 `static/js/travel-map-platform.js` 中的加载器，以及被 Git 忽略的 `.env.amap.local` 内的 `HUGO_AMAP_WEB_KEY` 和 `HUGO_AMAP_SECURITY_JSCODE`。密钥仅由本机接口提供，不写入图库、故事或公开构建；环境变量可以覆盖文件配置。
- 照片原始 GPS 按 WGS84 保留，高德显示用的 GCJ-02 坐标在浏览器本地转换，不调用在线坐标转换服务。海外地图启用高德的世界地图支持。
- 可在高德街道地图和离线 Natural Earth 底图之间切换，支持缩放、拖动、拍摄点标记；高德加载失败会回退到离线底图。使用 `--offline-map` 启动可从始至终禁止在线地图加载。
- 点选照片或拖动时间条，地图和照片时间线同步更新；**按时间回看** 按时间顺序播放。
- 没有 GPS 的照片保留在时间线中，不伪造坐标，也不调用在线地理编码。
- 线段仅连接照片记录的拍摄位置，不代表实际步行或行车路线。高德用于显示街道和位置，不调用驾车规划来伪造历史轨迹；离线底图不包含精细街道。

## 离线故事页面

**导出故事** 导出一个含内嵌预览图的中文 HTML 文件，接收者可以直接离线打开。按时间均匀选取最多 24、60 或 100 张本地可用预览，页面标示实际导出覆盖数量。

默认移除原始文件名、文件路径、精确 GPS 和图片 EXIF。位置选项默认关闭；开启后仅包含四舍五入到 `0.1°` 的粗略位置，约为十公里量级。相册标题、简介和拍摄日期会包含在页面中；照片笔记需要明确勾选。**故事仍包含照片本身，分享前应检查画面内容和简介。** 导出不会自动上传或发布。

## 本地边界

- 照片保持原位置。索引、预览、旅行相册和本地博客构建保存在被 Git 忽略的 `.local-photos/`。
- 应用源代码在 `local/photos/`，不在 Hugo 的 `content/`、`static/` 或 `assets/` 下。
- 博客导航入口要求 Hugo 环境恰为 `local-photos` 且本地配置启用。正常生产构建没有这个入口，也没有照片页面。
- 照片页面有 CSP；在线地图模式只放行高德所需的 `amap.com` / `autonavi.com` 域名，离线启动模式拒绝外站资源。本地 API 校验 Host、浏览器来源和修改令牌，禁止跨站访问。
- 高德域名鉴权需要请求来源；在线模式使用 `strict-origin`，仅提供本机页面的来源域名，不传出照片页面路径或查询内容。离线模式使用 `no-referrer`。
- `noindex` 是附加标记；真正的访问边界是本机监听和发布目录隔离。
- 元数据、GPS、分类、OCR 和向量保存在本地 SQLite 中。图片只交给本机离线模型和 OCR，不发送到远程模型服务。离线故事默认不包含 OCR、向量或模型分类内部信息。

macOS 拒绝访问时：在「系统设置 → 隐私与安全性 → 完全磁盘访问权限」启用运行工具的 Codex 或 Terminal，重启该应用后再次启动。也可使用从 Apple Photos 导出的本地文件夹。

底图来源：[Natural Earth land GeoJSON](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson)，公共领域数据，随工具保存后离线使用。

本地坐标转换复用 [coordtransform](https://github.com/wandergis/coordtransform)；原始代码与 MIT 许可证保存在 `ui/coordtransform.js` 和 `ui/coordtransform.LICENSE`。地图接口参见[高德 JS API 2.0](https://lbs.amap.com/api/javascript-api-v2/documentation)。
