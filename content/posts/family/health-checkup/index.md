## 基础体检项目（人人必做）

以下是每次体检都应包含的基础项目：

### 一般检查
- **身高、体重、BMI**：评估肥胖程度，BMI 正常范围 18.5–23.9
- **血压**：筛查高血压，正常值 < 120/80 mmHg
- **心率**：静息心率正常 60–100 次/分

### 血液检查
| 项目 | 筛查目标 | 关注指标 |
|------|---------|---------|
| 血常规 | 贫血、感染、血液系统疾病 | 白细胞、红细胞、血红蛋白、血小板 |
| 肝功能 | 肝脏损伤、肝炎 | ALT、AST、胆红素、白蛋白 |
| 肾功能 | 肾脏疾病 | 肌酐、尿素氮、尿酸 |
| 血脂四项 | 动脉粥样硬化风险 | 总胆固醇、甘油三酯、LDL-C、HDL-C |
| 空腹血糖 | 糖尿病筛查 | 空腹血糖 < 6.1 mmol/L |
| 糖化血红蛋白（HbA1c） | 近 2–3 个月平均血糖水平 | < 6.0% 正常 |

### 尿液检查
- **尿常规**：筛查肾脏疾病、泌尿系感染、糖尿病等

### 影像学检查
- **胸部 X 光 / 低剂量 CT**：筛查肺部疾病
- **腹部超声**：筛查肝、胆、脾、胰、肾的病变

### 心电图
- 筛查心律失常、心肌缺血等

### 眼科 & 口腔
- **视力检查、眼底检查**：筛查青光眼、高血压/糖尿病眼底病变
- **口腔检查**：筛查龋齿、牙周病

### 心脑血管专项
- **颈动脉超声**：评估动脉粥样硬化程度，建议 40 岁以上或有"三高"人群每年做
- **心脏超声**：筛查瓣膜病变、心肌肥厚等结构性心脏病
- **动态心电图（Holter）**：捕捉阵发性心律失常
- **冠脉 CT（CTA）**：高危人群筛查冠心病，不建议作为常规项目
- **同型半胱氨酸（Hcy）**：心脑血管独立风险因子

### 骨密度检查
- **DXA 双能 X 线骨密度**：绝经后女性及 50 岁以上男性建议每 1–2 年检查
- T 值 ≥ -1.0 正常；-1.0 ~ -2.5 骨量减少；≤ -2.5 骨质疏松

### 其他专项
| 项目 | 适用人群 | 说明 |
|------|---------|------|
| 幽门螺杆菌（Hp）检测 | 所有成人 | 碳 13/14 呼气试验，阳性建议根除 |
| 甲功五项 | 女性、疲劳/体重异常者 | 筛查甲亢、甲减 |
| 糖耐量试验（OGTT） | 空腹血糖处于临界值 | 确认糖尿病前期 |
| 维生素 D | 室内工作者、老年人 | 缺乏率极高，影响骨骼和免疫 |
| 乙肝五项 | 未接种或不确定者 | 确认是否有抗体保护 |
| 肝脏弹性检测（FibroScan） | 脂肪肝、肝炎患者 | 评估肝纤维化程度 |

## 不同年龄段的体检套餐建议

### 20–30 岁：打好健康基线

**核心目标**：建立个人健康数据档案

- 基础项目全套（血常规、肝肾功、血脂、血糖、尿常规）
- 甲状腺超声 + 甲功
- 乙肝五项（确认抗体状态）
- 幽门螺杆菌检测
- 女性：乳腺超声、宫颈 TCT
- 视力 + 眼底检查

### 30–40 岁：关注代谢与压力

**核心目标**：早期发现代谢异常，关注职场压力带来的健康影响

- 上述全部 +
- 糖化血红蛋白（HbA1c）
- 腹部超声（肝胆脾胰肾）
- 颈动脉超声（有"三高"或家族史者）
- 心电图
- 维生素 D
- 女性：乳腺超声 + HPV/TCT 筛查

### 40–50 岁：癌症筛查启动期

**核心目标**：系统性癌症筛查 + 心脑血管风险评估

- 上述全部 +
- **低剂量螺旋 CT**（肺癌筛查）
- **胃肠镜**（胃癌、结直肠癌筛查）
- 肿瘤标志物组合（AFP、CEA、CA199 等，作为辅助参考）
- 颈动脉超声
- 心脏超声
- 骨密度（女性围绝经期）

### 50 岁以上：全面深度筛查

**核心目标**：癌症复筛 + 退行性疾病监测

- 上述全部 +
- 骨密度（每年）
- 脑部 MRI（有头痛/家族脑血管病史者）
- 冠脉 CTA（高危者）
- 前列腺 PSA（男性）
- 肺功能检查
- 眼底照相（糖尿病、高血压患者）

## 关于肿瘤标志物的正确认知

很多体检套餐会包含"肿瘤标志物"检测（CEA、AFP、CA125、CA199、PSA 等），需要正确理解其价值：

| 认知 | 说明 |
|------|------|
| **不是确诊工具** | 标志物升高 ≠ 患癌，炎症、良性疾病、生理波动都可能导致升高 |
| **不是万能筛查** | 早期癌症标志物可能完全正常，不能靠标志物正常就排除癌症 |
| **需要结合影像** | 标志物的价值在于与超声、CT、内镜等影像学检查相互印证 |
| **纵向对比更有意义** | 单次值意义有限，持续升高的趋势比绝对值更重要 |
| **特定场景价值高** | 高危人群筛查（如 AFP + 超声筛查肝癌）、术后随访监测复发 |

> **结论**：不要盲目加做一堆肿瘤标志物，也不要因为某项指标轻微升高就恐慌。以影像学检查为主，标志物为辅。

## 体检前的准备事项

1. **空腹**：血糖、血脂、肝功等项目需空腹 8–12 小时（可少量饮水）
2. **避免剧烈运动**：检查前 1–2 天避免，可能影响肝功、心肌酶等
3. **停用特定药物**：某些药物影响检测结果，提前咨询医生是否需要暂停
4. **女性避开经期**：尿常规、妇科检查需避开月经期
5. **肠镜准备**：需提前低渣饮食 + 服用泻药清肠
6. **携带既往报告**：便于医生纵向对比

> - **基础一**（¥627）：满足最基础筛查，适合预算有限的年轻人
> - **基础二**（¥777）：相比基础一仅升级胸部 X 光 → 低剂量螺旋 CT，肺部筛查能力大幅提升
> - **甄选二**（¥1116）：性价比拐点，补齐了低剂量 CT、C14 呼气、眼底等关键项
> - **尊享一**（¥1456）：加入甲状腺彩超和肿瘤精选 7 项，适合 40 岁以上
> - **尊享二**（¥1739）：增加胃癌早筛和骨密度，适合 50 岁以上
> - **尊享三**（¥2261）：全面覆盖心血管、肝脏、肾脏、糖代谢深度指标，适合有基础疾病或 60 岁以上人群
>
> **个人选择建议**：
> - **33 岁（脂肪肝+超重）**：推荐**甄选二**为底，额外加做甲状腺彩超、糖化血红蛋白。如预算充足选尊享三（含 CK18-M30 脂肪肝专项）
> - **63 岁（传导阻滞）**：推荐**尊享二**起步，心脏彩超已查两次均正常，目前定期动态心电图监测即可、暂不加做。如预算充足选尊享三（含同型半胱氨酸、电解质等心血管深度指标）
