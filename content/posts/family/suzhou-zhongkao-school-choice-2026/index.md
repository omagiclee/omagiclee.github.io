以国内985为主要目标，同时保留英美顶校和港大、港中文、港科大路线，择校需要比较升学机会、学校资源与家庭投入。对于目前在吴江的家庭，核心问题是：**是否值得在小学阶段迁到其他区域买房读书，还是可以等到初一入学前再迁区。**

政策依据为2026年，范围为姑苏、园区、高新区、吴江、吴中、相城六区；昆山、常熟、太仓、张家港另查当地规则。资料截至2026年10月7日，未来入学和中考按当年政策核对。

## 小学前迁区买房的判断 {#primary-move-decision}

**现行政策支持认真比较“初一前迁入三区”，但没有“小学必须先在目标区读六年”的通用要求。** 因此，中考跨区分差可以说明迁区的升学价值，尚不足以单独决定小学前就买房搬家。初一能否进入具体学校，仍取决于届时入学条件和学位供给。[2026市区初中入学条件](https://jyj.suzhou.gov.cn/szjyj/zszc/202605/004575bf5f894dcd837274b6cfc3cc4d.shtml)、[三区入学信息采集指南](https://www.suzhou.gov.cn/szsrmzf/mszx/202605/0248b2ff3d614d2c9e98bfe347f84913.shtml)

这里的“三区”指姑苏、工业园区、高新区。三者属于同一高中招生区域；**选园区还是新区、姑苏，应进一步比较具体小学和初中，不能仅凭区域名称判断中考优势。**

{{< codex-table label="小学迁区初中迁区与留吴江的比较" compact="true" >}}

| 安排 | 主要收益 | 决定前要核实 |
| --- | --- | --- |
| 小学前迁入三区 | 提前获得目标小学的教学、同伴和生活环境；为以后初中入学作准备 | 小学实际优势、初中衔接条件、额外住房与通勤成本 |
| 小学留吴江，初一前迁入三区 | 保留小学阶段现有生活安排；合规进入三区初中后，可争取当地高中通道 | 目标初中的入学条件及材料准备时点，不能保证小六再开始购房就来得及 |
| 小学和初中均留吴江 | 本区高中指标、统招、自主与项目；外区跨区及符合条件的六区项目 | 吴江具体初中、目标高中班型的资源，外区跨区竞争 |
| 选择吴江民办小初 | 学校实际提供的教学与课程；符合当年规则的校内衔接 | 小升初计划、个人指标资格、国内高中与国际高中的分别录取条件 |

{{< /codex-table >}}

如果主要看重苏中、星海、苏州实验等高中的区域内招生机会，应先比较“初一前迁区”的可行性。若某所小学在同伴、教学管理、学习习惯或适合孩子的课程上已有明确优势，且家庭能承担搬家成本，再进一步判断是否值得提前到小学阶段。

## 小学留吴江初中再迁区的条件 {#move-before-junior}

### 小学所在地不会单独锁定初中区域

2026年公办初一入学对象按监护人合法固定住所及实际居住、户籍、积分等条件确定。三区信息采集指南要求按监护人合法固定住所所属地选择区域，无合法固定住所的符合条件家庭按户籍等路径办理；未将“必须在目标区读小学”列为通用前提。[市级义务教育招生意见](https://www.suzhou.gov.cn/szsrmzf/bmwj/202605/27e3ba482e8d408e91d465d4480916ba.shtml)、[三区信息采集指南](https://www.suzhou.gov.cn/szsrmzf/mszx/202605/0248b2ff3d614d2c9e98bfe347f84913.shtml)

据此，**小学在吴江，按新住所等合规条件申请三区初一，是现行规则下可考虑的路径**。这与不符合当地条件的跨区择校、借读不同；个人是否满足地段生及指标条件，仍须审核。

### 初一入学和中途转学的区别

中考指标生须满足地段生认定或积分入学等相关要求，并在**服务片区初中连续在籍在读满三年**。如果准备迁区，应在初一入学前落实就读方案，并按目标学校要求更早准备房产、户籍、实际居住等材料；不能把“初一前落实”理解为统一的购房截止日期。[2026市区中招通知](https://www.suzhou.gov.cn/szsrmzf/bmwj/202605/4a9271ac8d7049f8ac0e6f310e79bc57.shtml)

初中中途转入通常难以满足连续三年的要求，还需接收学校有学位。吴江2026年规定，接收插班生须有空余学位并符合规定，已达到招生计划的民办学校不得安排转入；就读学校、录取记录和学籍应保持一致。[吴江义务教育招生意见](https://www.wujiang.gov.cn/zgwj/c111618/202606/fbf10240e0974d11b593e2353c831891.shtml)

符合条件的学生可以回户籍地报名中考，**回户籍地考试不会自动补齐当地指标资格**。获批贯通项目有特殊学籍安排时，须按项目文件另行确认。[市区中考报名与指标规定](https://www.suzhou.gov.cn/szsrmzf/bmwj/202605/4a9271ac8d7049f8ac0e6f310e79bc57.shtml)

### 买房与进入指定学校需要分别确认

符合规定的住宅产权是认定施教区的重要依据，还须结合实际居住、户籍等条件审核。学区可能调整；报名超过学校计划或承载能力时，按当年公示规则录取。**买房前应核实具体房屋对应的学校和录取条件，不能只凭房源标注“学区房”判断。**[市级义务教育招生范围规定](https://www.suzhou.gov.cn/szsrmzf/bmwj/202605/27e3ba482e8d408e91d465d4480916ba.shtml)

购房也不是所有家庭唯一的入学渠道，符合条件的户籍统筹、积分、政策性安排及民办录取等路径仍存在。不过，租房或持居住证不能直接确认指定热门公办学校的资格，现有房产情况还会影响可用路径。先按家庭实际条件确认目标学校的合法入学方式，再决定是否必须购房。[市区入学政策问答](https://jyj.suzhou.gov.cn/szjyj/zszc/202605/004575bf5f894dcd837274b6cfc3cc4d.shtml)、[园区入学条件与积分问答](https://www.sipac.gov.cn/szgyyq/whjy/202605/20fb559af0344bab9ae53f00e3ceb620.shtml)

## 迁入三区增加的高中机会 {#regional-opportunities}

### 招生区域决定普通计划的报考范围

2026 年，六区并非一个可以自由报考所有普通高中的招生区域：

| 所在区域 | 常规区域内招生范围 |
| --- | --- |
| 姑苏区、工业园区、高新区 | 三个区属于同一招生区域 |
| 吴江区 | 独立招生区域 |
| 吴中区 | 独立招生区域 |
| 相城区 | 独立招生区域 |

除特别注明的项目外，考生按所属招生区域选择学校。部分高中另设面向六区的跨区计划，采用 **10 个平行志愿**，在所有中招志愿录取批次之前录取。[苏州市教育局 2026 招生政策问答](https://jyj.suzhou.gov.cn/szjyj/zszc/202605/004575bf5f894dcd837274b6cfc3cc4d.shtml)

迁到园区或新区需要取得当地入学、报考资格；在吴江报名中考，报考本文所列外区公办高中的普通计划，主要依靠当年跨区计划。比较分数线时，应区分区域内统招线、指标线和跨区线。经批准的特殊培养项目另有招生范围，例如苏中匡亚明2026年明确面向六区，见[学校资源与特殊培养项目](#school-resources)。

吴江考生走普通跨区计划进入同一所三区高中，近年往往需要更高分数。2026年苏中本部跨区比区域内统招高8分、星海苏茜路高11分、苏州实验本部高12分、西交方洲路高9分。**没有固定“跨区加16分”的规则**；差额来自不同招生计划的录取结果，不是对吴江考生额外扣分。完整对照见[五年录取线与分差](#10所重点高中20222026年录取线)。

迁区的另一项价值是符合条件后可竞争当地初中分到的指标，以及区域内自主招生、学科项目。仅看跨区与统招分差，尚未计入这些通道，也没有计入校内竞争。

### 指标资格和本初中的竞争

2026 年市区中招通知规定，四星级普通高中指标生比例为招生计划的 **70%**，按符合条件的毕业生人数分配到统招区域内初中。享受政策须满足地段生认定或积分入学等其他相关要求，并满足[连续在籍在读三年的要求](#move-before-junior)。指标录取仍须填志愿、达到录取要求。[2026 年市区中招通知](https://www.suzhou.gov.cn/szsrmzf/bmwj/202605/4a9271ac8d7049f8ac0e6f310e79bc57.shtml)

姑苏、园区、新区的专项通知进一步明确：70% 的计算基数**不包含跨区、自主招生及各类项目计划**。假设某高中总计划 1,000 人，扣除这些计划后剩 800 人，指标计划就是 560 人，而非 700 人。[三区 2026 指标生分配通知](https://www.suzhou.gov.cn/szsrmzf/bmwj/202606/47a0ac6e7af64325bb05b3be28a8b210.shtml)

### 指标名额和招生计划

同一校区应分别列出**普通跨区、区域内指标、区域内普通统招、普通自主招生、学科或贯通项目、国际及其他项目**的人数，再标记孩子能报哪几项。学校总计划不能全部当作某一地区考生的可报名额；项目人数也不能重复计入普通自主招生。2026年未招满的跨区、自主、项目、国际课程和指标计划须转入该校统招，最终统招人数可能与最初计划不同。[2026年招生计划与剩余计划处理](https://www.suzhou.gov.cn/szsrmzf/bmwj/202605/4a9271ac8d7049f8ac0e6f310e79bc57.shtml)

2026年三区官方指标分配表可核对以下总数。这些是高中分给三区初中的指标总量，**吴江初中不参与这张表的分配**。

| 高中或校区 | 区域内指标总人数 |
| --- | ---: |
| 苏州中学本部 | 174 |
| 星海苏茜路 | 167 |
| 星海沈浒路 | 446 |
| 苏州实验本部 | 206 |
| 西交大苏州附中方洲路 | 391 |

来源：[三区2026指标分配官方附表](https://www.suzhou.gov.cn/szsrmzf/bmwj/202606/47a0ac6e7af64325bb05b3be28a8b210.shtml)，人数为附表各初中对应列合计。各校完整通道人数仍须核对当年招生专刊；指标数不能反推完整计划，跨区分数线也不能替代跨区招生人数。

### 初中的指标竞争怎么比较

指标按符合条件的学生人数分配，并非按学校声誉分配。官方表中，星海实验中学符合统计口径的学生为748人，分得苏中4人、星海苏茜路4人、星海沈浒路10人。名校初中拥有优秀同伴和较强教学资源的可能收益，要与校内目标高中指标的竞争一起评估。[2026指标分配办法与星海初中名额](https://www.suzhou.gov.cn/szsrmzf/bmwj/202606/47a0ac6e7af64325bb05b3be28a8b210.shtml)

比较具体初中时，至少取得：**目标高中指标数、个人是否合资格、同届合资格人数、近年该高中指标实际录取最低分或校内位次、达到控制线且填报该志愿的人数**。名额与合资格人数之比只能描述配额密度，不能直接算个人录取概率；强初中的同伴与教学收益，也不能仅用指标竞争否定。

**指标最低控制线是资格门槛，不是保证录取的分数。** 例如2026年苏中指标最低控制线按统招线以下20分以内设定；达到控制线后，仍在本初中对应高中分配名额内，按志愿和成绩录取，不能理解成所有学校或所有指标生固定降20分。[三区指标录取标准](https://www.suzhou.gov.cn/szsrmzf/bmwj/202606/47a0ac6e7af64325bb05b3be28a8b210.shtml)

吴江的比较须使用**吴江当年各初中分配表与实际指标录取结果**。当前仍缺可核对的2026年吴江逐初中完整分配表，不能用三区表或往年吴江名额替代。这项数据会影响“吴江哪所初中更合适”的判断。

### 民办初中也有指标，个人资格须另确认

2026 年三区分配附件中，国裕外语、新草桥、园区外国语、海归人才子女学校等民办初中均获分配指标。[2026 指标生分配附件](https://www.suzhou.gov.cn/szsrmzf/bmwj/202606/47a0ac6e7af64325bb05b3be28a8b210.shtml)

学校有名额，不代表每名学生都有资格。报名前，应向属地教育部门说明**具体学校、入学方式（摇号或直升等）及学生身份**，确认个人资格、连续在籍在读的计算方法和文件依据。

公办地段生、积分入学学生须按相应身份审核；民办学生按个人入学身份及所在区规则审核。连续就读与转学的影响见[初一入学和中途转学的区别](#move-before-junior)。

### 区域内自主招生与学科项目

苏州现行的四星级普通高中自主招生，是**初中升高中**的招生方式：

| 要点 | 2026 年规则 |
| --- | --- |
| 招生范围 | 普通自主招生按所属行政区域和具体学校简章审核，不能直接视为三区互通 |
| 普通自主招生名额 | 不超过当年学校招生计划总数的 5% |
| 综合成绩 | 中考折算成绩占 70%，面试折算成绩占 30% |
| 中考要求 | 须达到所在区域自主招生最低控制线 |
| 报名 | 每位考生限报一所，审核后参加面试 |

未获自主招生录取的考生，可按已填中招志愿继续录取；选择自主招生并完成规定报到后，不再进入后续志愿流程。[2026 普通高中自主招生通知](https://www.suzhou.gov.cn/szsrmzf/bmwj/202605/7b3dd33345cd40eea1894ef727c0bcda.shtml)

面向普通类高考的**学科类实验项目**另有批准名单，例如钱学森班、国科大创新实验班等；其报名、评价与录取参照自主招生办法，面向学校统招区域同步进行。项目名额应单独查招生计划，不能一概套用普通自主招生的 5% 上限。[同一通知附件：学科类实验项目](https://www.suzhou.gov.cn/szsrmzf/bmwj/202605/7b3dd33345cd40eea1894ef727c0bcda.shtml)、[官方问答第3问：行政区域与统招区域的区别](https://www.suzhou.gov.cn/szsrmzf/mszx/202606/571d46b572424923af354bc23f6f65cd.shtml)

### 苏州中学园区校的名额拆分示例 {#school-quota-example}

以**苏州中学园区校2026年**为例，公开汇总表列出的六类计划合计 **300人**，具体拆分如下。表格按录取先后排列，同一顺序的两项同步录取。

{{< codex-table label="苏州中学园区校2026年招生名额与录取顺序示例" >}}

| 顺序 | 通道 | 计划人数 | 竞争范围与条件 |
| --- | --- | ---: | --- |
| 1 | 普通跨区 | 60 | 六区符合条件的考生按志愿和中考成绩竞争；不是专门留给吴江的60人 |
| 2 | 普通自主招生 | 19 | 简章列明姑苏区学籍应届生，以及符合返市区报考条件的姑苏区户籍应届生 |
| 2 | 钱学森班学科项目 | 55 | 简章列明姑苏、新区、园区应届生；与普通自主招生是两个独立计划 |
| 3 | 国际课程 | 30 | 提前批第二阶段第3小批；须符合招生范围，单独报名、通过外语加试并填志愿 |
| 4 | 指标生 | 95 | 第一批第一阶段；先分到三区各初中，个人合资格且达到控制线后，在本初中相应名额内竞争 |
| 5 | 区域普通统招 | 41 | 第一批第二阶段；三区符合条件的考生按志愿和中考成绩竞争 |

{{< /codex-table >}}

**来源与核实程度：** 95个指标由[官方分配附表](https://www.suzhou.gov.cn/szsrmzf/bmwj/202606/47a0ac6e7af64325bb05b3be28a8b210.shtml)各初中对应列合计核对；19与55见[学校简章转载](https://www.yidianedu.com/xuexiao/article?id=3431)；60、30、41取自[一点升学招生计划汇总](https://www.yidianedu.com/xuexiao/detail?school_id=636)，尚未取得官方完整计划表复核。**300是这六类的合计，不能据此认定为全校全年完整招生总数。** 录取顺序依据[市区中招通知](https://www.suzhou.gov.cn/szsrmzf/bmwj/202605/4a9271ac8d7049f8ac0e6f310e79bc57.shtml)。

这个例子有三个直接影响择校的区别：

- **吴江初中与三区初中能竞争的名额不同。** 仅看本例列出的国内高考通道，吴江考生主要通过60人的跨区计划报考；合规迁入三区后，才可能增加指标、区域统招及钱学森项目的选择。普通自主招生的19人还须满足姑苏区条件，迁到园区或新区并不自动获得资格。
- **95个指标不是所有三区学生一起竞争。** 例如官方表中星海实验初中分到园区校2人：合资格学生在本初中这2个名额内竞争，并须达到控制线、填报相应志愿。41个普通统招则是区域内竞争。两者合计136人，95约占70%；70%不能乘以六类合计300。
- **前面录取会结束后面的机会。** 跨区录取后不再参加自主、指标和统招；自主招生按规定选择并确认录取后，也不再进入后续志愿流程。国际课程先于指标、统招录取，填报前须先确认是否愿意走这条路线。

**未招满的名额会改变后续统招人数。** 假设国际课程剩3人、各初中指标合计剩2人，且其他计划均录满，则原来的41个统招可增加为 **41＋3＋2＝46人**。这是演算示例，非该校实际剩余人数；处理依据为[官方问答第5问](https://www.suzhou.gov.cn/szsrmzf/mszx/202606/571d46b572424923af354bc23f6f65cd.shtml)。

### 录取顺序影响志愿选择

主要顺序为**跨区 → 区域内自主招生及学科项目 → 提前录取 → 第一批录取 → 后续批次**。苏中、震泽、木渎的指标与统招在提前录取第一阶段，其他相应指标安排在第一批第一阶段。跨区志愿只填愿意就读的学校并按实际偏好排列；被前面批次录取后，不再参加后续批次。[2026市区中招批次规定](https://www.suzhou.gov.cn/szsrmzf/bmwj/202605/4a9271ac8d7049f8ac0e6f310e79bc57.shtml)、[平行志愿规则](https://jyj.suzhou.gov.cn/szjyj/zszc/202605/004575bf5f894dcd837274b6cfc3cc4d.shtml)

## 学校资源与特殊培养项目 {#school-resources}

### 小学阶段提前搬家的教育收益

更好的同伴、教学管理和课程可能让孩子在相同投入下学得更扎实。这类收益应落到具体小学：课堂秩序与反馈是否更好，教师是否稳定，阅读、数学和英语是否有连贯安排，家庭课外补习负担是否更低，睡眠和日常运动能否保障。区域名气或高中录取线不能代替这些比较。

提前迁区还可能增加适应新环境的时间、减少后来换校的衔接问题。需要同时核实目标小学与初中的实际招生关系；小学毕业并不自动保证指定初中，更不意味着获得某所高中的名额。若主要收益要到初中才出现，就应把“小学迁区”和“初一前迁区”并排比较。

### 初高中资源是否能惠及自己的孩子

学校优势要落实到**具体校区、班型和可参与课程**。向学校询问以下信息，比只看一本率或清北人数更能判断收益：

| 比较项 | 要取得的具体信息 |
| --- | --- |
| 同伴与学习氛围 | 同届生源构成、班级学风、合作与竞争方式，孩子预计所在班型 |
| 教学与管理 | 教师稳定性、作业和讲评质量、薄弱学科反馈、睡眠及心理支持 |
| 分班与调整 | 项目班如何选拔，何时调整，普通班可否参加拓展和竞赛课程 |
| 竞赛与强基 | 实际在岗教练及学科、课程覆盖人数、每周耗时、退出后的学业衔接 |
| 综评与港校支持 | 谁负责材料和时间节点，是否覆盖普通班，英语表达与校测支持如何安排 |
| 近年升学结果 | 同校区近三年毕业人数、985实际录取去重人数，区分普通班、项目班、复读生与国际部 |

例如苏中匡亚明方案明确设置竞赛、强基及国家课程的结合，但这是该项目的培养安排，不能自动当作所有班级都能获得的支持。[匡亚明课程方案](https://www.szzx1000.cn/e/action/ShowInfo.php?classid=17&id=11349)

**985录取率须有同届、同口径的毕业人数作分母，并分别看班型、校区及复读生。** 还应对照入学时成绩位次：优秀生源本身会提高学校升学率。现有录取线表尚不足以判断“同等基础的孩子在哪所高中更容易上985”。

## 国内985与国际升学的路线选择 {#university-options}

苏州内部迁区主要改变中考机会和学校资源。按现行普通高考制度，吴江、园区、新区、姑苏等地在江苏报考的学生，在同一报考类别内竞争高校在江苏的计划；迁区本身不带来普通高考分区名额优势。优质高中可能提供更好的教学、竞赛和申请支持，但没有专属“985指标”。[江苏2026年高校招生计划及类别](https://www.jseea.cn/webfile/index/index_zkxx/2026-06-23/7474808080111243264.html)

### 国际课程与国内路线的衔接

**2027年起，全市民办高中将纳入统一中招系统，与公办同步填报志愿、投档录取和注册学籍。** 因此，应在以后官方数据公布后更新民办比较；不能把2022—2026年的自主选拔方式直接套到未来升学。[苏州市教育局2026招生政策问答](https://jyj.suzhou.gov.cn/szjyj/zszc/202605/004575bf5f894dcd837274b6cfc3cc4d.shtml)

纳入中招的普通高中国际（境外）课程项目，2026 年安排在提前录取第二阶段第 3 小批：单独报名、填报对应志愿、通过外语加试，再按中考成绩录取，并设中考及英语最低要求。[2026 市区国际课程录取规则](https://www.suzhou.gov.cn/szsrmzf/bmwj/202605/4a9271ac8d7049f8ac0e6f310e79bc57.shtml)

**未达到本校当年普高班录取线的学生，在读期间不得转入普高班。**[2026 普通高中招生意见：国际课程](https://www.suzhou.gov.cn/szsrmzf/bmwj/202605/0ea5b9ae2fac47ac8432c3cfff85f355.shtml)

申请阶段可保留选择，进入录取后存在排他性：确认就读香港单独招生高校后，不再参加内地统一录取；港中文提前批未录取可继续后续批次，已录取则不能继续等后续内地高校。[阳光高考2026港澳报考指南](https://gaokao.chsi.com.cn/gkzt/gagx2026)、[港中文提前批规则](https://admission.cuhk.edu.hk/sc/application/mainland-gaokao/admission/)

若目标扩大到英美顶校，应另行比较国际课程的学科开设、学术支持、英语写作、升学顾问负担、近三年目标大学实际入读人数，以及全程学费和生活费。不能用“海外名校录取通知总数”替代目标学校的入读人数，也不能由小学双语标签推断未来申请优势。国内985与英美顶校并行准备的时间成本，应在决定高中课程时单独评估。

## 买房前的比较清单 {#before-buying}

先选出吴江现可就读的小学、初中，以及三区两至三个候选“小学＋初中”组合。把学校、资格、升学机会和成本放在同一张表里，避免只比较区域声誉或房源宣传。

{{< codex-table label="为教育迁区买房前需要确认的事项" compact="true" >}}

| 比较项 | 要落实的信息 |
| --- | --- |
| 小学提前迁区的收益 | 候选小学的同伴、课堂反馈、管理和课程，比吴江可选学校具体好在哪里，能否减少家庭额外投入 |
| 指定初中的入学确定性 | 当年施教区、产权与户籍条件、实际居住、学位使用情况、超额录取规则，材料最晚何时准备；买房后能否按地段生入学 |
| 初中到目标高中的机会 | 个人指标资格、具体高中配额、同届合资格人数、近年实际指标线或位次；区域内统招、自主及项目分别有多少名额 |
| 高中培养的实际收益 | 孩子可能进入的校区与班型，课程覆盖、师资、作业和竞赛耗时，同口径的985或目标海外大学实际入读人数 |
| 家庭增加的成本 | 两种搬家时点分别增加的住房占用、交易与持有成本、通勤、学费、照护，以及孩子适应和休息时间 |

{{< /codex-table >}}

学位使用情况应按目标区、目标学校核实，不能把某一区的“小学、初中五年一学位”做法套用到全市。若计划保留原住房并另购一套，市级规则原则上以相对稳定、具备长期生活条件的住所认定施教区，也应提前确认。[公办地段生与多处住所认定](https://jyj.suzhou.gov.cn/szjyj/zszc/202605/004575bf5f894dcd837274b6cfc3cc4d.shtml)

目前影响买房判断的缺口主要是**具体小学的比较、目标初中的入学准备时点，以及两地实际指标竞争**。吴江2026年逐初中的完整指标分配与实际录取结果尚未取得；目标高中班型的资源覆盖和同口径升学数据也需要进一步核对。

### 各阶段需要完成的决定

| 阶段 | 重点决定与核验 |
| --- | --- |
| 幼儿园至小学报名之前 | 比较具体小学；核实小学及未来初中的入学条件，决定是否为小学收益提前迁区 |
| 小学低中年级 | 观察孩子能力与学校适配；保留迁区选择，持续核对目标初中的资格准备要求 |
| 小学高年级至初一入学前 | 落实初中入学方案与个人指标条件，提前完成所需材料；关注伟长等小升初项目 |
| 初中三年 | 保持合规学籍与连续就读；结合学业、兴趣和学校支持评估国内或国际方向 |
| 初三填报之前 | 按当年专刊拆分可报计划，核对指标、项目、录取顺序与高中课程路线 |
| 高中阶段 | 确认选科、班型与培养资源，按时准备强基、综评、竞赛或海外申请；港校独立申请可能早于高考出分 |

**先比较“小学迁区”与“初一前迁区”各自能增加什么，再决定住房。** 若目标小学已有明确教育收益且入学路径可落实，提前搬家更有依据；若收益主要来自三区中考通道，应重点核实初一迁区方案和准备时点，不必仅凭现在的高中分差作出小学购房决定。
