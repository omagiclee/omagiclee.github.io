本篇承接[家庭保险基础知识扫盲]({{< relref "../insurance-basics/index.md" >}})和[家庭医疗险配置指南与高效选品策略]({{< relref "../insurance/index.md" >}})，将个人保障目标落实为产品、价格与合同条件的比较。**本次优先完成医疗险选型，重疾险只保留目标。**

**当前建议：长期普通部保障与当期特需保障分层配置。以太保好医好药标准版B，加大地/MSH欣享人生2026 B零免赔版作为首选核保组合，公开首年标准费合计3,196元。众安PLUS与安盛特需C是两组重点备选。** 这是一份待核保、待确认医院网络的选型建议，尚非个人承保报价。

## 1. 已确定的保障目标

我参加上海职工医保，公司另有补充商业团险，可补充部分日常医疗费用，但不含特需。个人保单需要考虑离职后仍能持续的保障。

| 项目 | 本次目标 |
| --- | --- |
| 被保险人及险种 | 仅本人；医疗险优先，重疾险随后；暂不比较寿险、失能险 |
| 就医范围 | 国内公立普通部；重大疾病可用符合合同约定的公立特需／国际部 |
| 日常门诊 | 不另购；目前由医保、公司团险及自付承担 |
| 必须保留的门诊 | 住院相关前后门急诊、肿瘤特殊治疗、透析、移植后抗排异、门诊手术等 |
| 医疗费用 | 尽量降低最终自付和治疗时的垫付压力 |
| 续保 | 普通部大额保障长期稳定；单独审视特需责任的续保期限 |
| 一般疾病特需 | 尚未最终决定；本篇比较仅大病特需与一般病也开放两条路线 |
| 私立、海外治疗 | 不作为购买理由；不主动加购可选海外责任 |

**不买日常门诊，不等于只保住院。** 特殊治疗门诊与普通看病、配药不同；住院前后门诊通常要求与该次住院同一原因并受时间窗口限制，普通长期复查不一定包含。

## 2. 比较口径

核验日期为 **2026年10月2日**。保费统一使用**32周岁、男性、有基本医保、单人、首投有等待期、年缴、标准体公开费率**，不计家庭折扣、促销或健康奖励。年龄、核保加费、渠道配置和续投费率均可能改变价格。

价格已尽量包含必要绑定责任，以及用于比较的院外药械责任。不同产品的药械目录、适应症和服务要求仍不相同；“完整组合”不表示所有药械都能报销。少数计划内置私立或境外特药责任，无法拆除时计入总价，但不为这些权益额外选更高档。

本次覆盖太保、众安、大地/MSH、安盛、友邦、复星联合、泰康、平安、人保健康、京东安联等主要相关候选；**这是按本需求筛选的主流样本，不是全市场穷尽清单。** 未取得同龄完整报价或当期合同的产品单列，不拿广告“起售价”补空。

## 4. 真正影响这次选择的五个差异

### 4.1 零免赔与低自付是两件事

为隔离赔付比例的影响，假设已过等待期、满足疾病定义与授权要求，费用均在保障范围和分项限额内，无其他保险补偿；特需医院因自身原因无法医保结算。下表仅计算**医疗费免赔与共付**，不模拟全部实际账单。

{{< codex-table label="相同特需治疗费用下的自付演算" >}}
| 方案 | 20万元符合定义的重大疾病特需治疗 | 3万元一般疾病特需治疗 |
| --- | ---: | ---: |
| 太保B或E＋全面特需B | 0 | 10,000 |
| 众安PLUS计划一0免赔 | 0 | 0 |
| MSH B0免赔 | 0 | 0 |
| 安盛特需C0免赔，实际保单有医院原因例外 | 0 | 0 |
| 友邦特需A | 40,000 | 6,000 |
| 复星全疾病特需0免赔，触发未医保60% | 80,000 | 12,000 |
{{< /codex-table >}}

演算依据分别为上述产品的免赔和赔付规则。[^cpic][^za][^msh][^axa][^aia][^fosun] 友邦5万元是**责任内共付**的年度门槛，不是全部自付上限。床位超标、除外费用与超限药械仍可能额外自付。

太保E计划三的“普通部最多自付2,000元”也只能描述特定一层：按医保结算、其他补偿后，合规普通部年度费用第一万元中的20%。它不能扩展为全年度医疗自付封顶，也不会消除一般特需的1万元免赔。[^cpic]

### 4.2 特需覆盖要与续保期限分别看

太保B/E的普通部主险保证续保20年，但特需附加险一年期不保证续保；E的特药附加险也为一年期，B的相应特药责任则在长期主险内。MSH、众安PLUS、安盛和友邦均不能作为“已经锁定长期特需资格”的证据。[^cpic][^msh][^za][^axa][^aia]

**MSH的实际续保案例应与合同承诺一起看。** MSH于2025年6月19日发布的官方案例披露：一位2024年确诊胃癌的客户，截至2025年6月累计获赔164,885元，治疗期间仍正常续保；另一位2021年确诊乳腺癌的客户累计获赔688,347元，文章发布时仍在保。这是欣享人生历史客户重疾后继续获保障的正面证据。它由服务方披露，未公开完整保单、全部续投结果或统计分母，不能据此计算续保成功率，也不能替代2026合同的续保约定。本次公开检索未找到能核实为该产品在保患重疾后拒续的负面个案；这不代表从未发生。[^msh-renewal]

复星把特需放进20年保证续保合同，长期资格更好，但现有条款中的医保降赔与低自付目标冲突；其渠道投保须知还出现“不可与其他费用补偿型医疗保险同时投保”，是否涉及已有公司团险需要书面确认。不能只看“20年”就判定优胜。[^fosun]

### 4.3 门诊治疗和药械，需要逐项核对

| 产品 | 相关住院前／后门急诊 | 核心治疗门诊 | 药械注意点 |
| --- | --- | --- | --- |
| 太保B/E及上述特需附加 | 30／30天 | 合同约定肿瘤治疗、透析、抗排异、门诊手术 | 普通部长期责任与一年期附加责任分别判断；特药目录与处方条件适用 |
| 众安PLUS2026 | 60／60天 | 同类治疗；癌症责任定义另含轻度、原位癌 | 外购药械清单按合同失效日前国家批准目录确定，并扣除免责项目；耐用设备等另有限额 |
| MSH欣享人生B | 30／30天 | 肿瘤治疗、透析、抗排异、门诊手术／日间治疗等 | 院内缺药／缺器械时，凭处方于认可机构外购；受相应福利、批准范围及授权限制 |
| 安盛特需C | 30／30天 | 肿瘤治疗、透析、抗排异、门诊手术等 | 院外特药与器械包须加齐；目录和独立医保规则另核对 |
| 友邦智选逸生 | 30／30天 | 肿瘤治疗、透析、抗排异、门诊手术等 | 一般院外药械10万元、80%；特定药械另有责任 |
| 复星星相守2号 | 45／45天 | 肿瘤治疗、透析、抗排异、门诊手术等 | 院外恶性肿瘤特药可选；未医保规则不能忽略 |

**不能仅以“有清单”判断众安药械范围狭窄。** 当前利益表将外购药械范围与合同失效日前国家药监部门批准目录相连，仍需遵守处方、适应症、除外及审批条件；不能与固定少量药品的特药白名单混为一谈。[^za]

以上均可在不加日常门诊的前提下保留相应治疗责任。各产品的疾病定义、治疗方式与医院条件并非完全一致。[^cpic][^za][^msh][^axa][^aia][^fosun]

### 4.4 能报销，不等于不用先掏钱

- **MSH B：**网络内住院可申请直付，非网络住院可申请垫付；B计划书并未把全部治疗门诊都列为直付。计划治疗须预授权，未按规定授权可能按原比例的50%给付，急诊一般要求48小时内通知。[^msh]
- **众安PLUS：**网络内的住院、肿瘤治疗、透析、抗排异及其他约定项目，须至少提前5个工作日申请预授权；未获授权原则上不承担给付，急诊48小时内通知。这是明显影响可用性的合同条件。[^za]
- **安盛：**样本保单对医院自身原因不能医保结算给予100%例外；公开垫付服务却仍对医保结算有要求。不能从“可以100%报销”推导出特需一定可以垫付。[^axa]

所以，除最终自付之外，还需要核对目标公立医院的**具体院区、具体部门、住院和治疗门诊分别能否直付**。医院有特需部门，不代表该部门自动属于每家保险的保障或服务网络。

### 4.5 既往症和免责可能改变排序

最终采用核保后保单，而非宣传页决定胜负。标准报价不能证明既往病史可以承保或相关费用可以获赔。

MSH B含既往症版须告知并获批准，公开方案只有1万／2万元免赔，对应32岁首年1,825／1,428元，**没有此版本的B零免赔档**。获批既往症责任首年5,000元、次年1万元、第三年1.5万元、第四年起按计划，仍受连续重新投保及其他条件约束。[^msh]

众安PLUS在连续投保到第四张保单后，部分责任可不受既往症和特别除外限制；前三张不因此承保既往症。它仍是一年期不保证续保，不能理解为“买三年就一定能保既往症”。[^za]

## 6. 推荐方案

### 首选核保组合：长期普通部＋MSH B零免赔

**太保好医好药B主险271元＋大地/MSH欣享人生2026 B零免赔2,925元＝3,196元／年。**[^cpic][^msh]

**271元和2,925元是两张独立保单的首年标准年费。** MSH的2,925元本身已含普通部、特需及相关治疗门诊，并非只购买特需附加责任；可以独立购买，不必先买太保。增加太保属于额外的长期保障安排，两份保障重叠，费用不能重复报销。只买MSH对应2,925元／年，组合才是3,196元／年。

这套组合分别承担两个任务：太保保留普通部长期保障；MSH在当期提供普通部及公立特需的低自付保障，并通过有条件的住院直付／垫付降低资金周转压力。选择一般疾病也开放特需，是为了让确诊前、未达到合同重疾定义时的住院选择更灵活。

MSH B零免赔、责任内100%、包含治疗门诊，适合本次优先降低自付的目标；它比众安组合贵291元／年。将其放在首选核保位，主要是其住院服务结构和相对较轻的未授权赔付后果；**不意味着所有药械、所有医院或现有健康异常均已获得保障。** 床位2,500元／日及既往症承保结论必须满足预期，否则应调整排序。部分独立合资国际机构可能除外，须核实院区、部门及收费主体，不能只按医院品牌判断。[^msh][^za]

MSH B首投住院及特殊门诊等待期30天，海外特药90天；连续不间断重新投保符合条件时免等待期。众安PLUS医疗等待期30天。太保B/E首投疾病医疗通常90天，意外等例外按各合同处理。新单生效不意味着疾病责任立即可用。[^msh][^za][^cpic]

**为什么长期底层选B，而不是免赔更低的E？** 升级层正常有效时，MSH已承担普通部低自付；B还把相应院外特药责任放在20年主险内，E则将这部分特药配置为一年期附加险。E长期主险的外购药械条款对靶向、免疫药另有限制，当前材料未见把该路径全部转入长期责任。选择B主要考虑长期大额药费的连续性，同时承认失去升级层后首万元自付的取舍。这里不表示E不保院内符合责任的靶向、免疫治疗。[^cpic]

两份医疗险重叠部分不能重复获赔。多付271元的目的，是在健康条件允许时保留长期普通部合同；如果一年期升级险未来无法续投，普通部保障仍可在长期合同规则内继续。届时特需资格、零免赔和直付服务不会自动保留，太保普通部仍有1万元免赔。[^cpic][^msh]

### 两个重点备选

| 组合 | 首年标准费 | 适合的取舍 |
| --- | ---: | --- |
| 太保B＋众安PLUS2026计划一0免赔 | **2,905** | 床位3,000／日，住院前后60天；接受严格预授权流程，核实药械条件及目标医院服务 |
| 太保B＋安盛卓越馨选2025特需C0免赔完整药械 | **2,630** | 成本更低；接受重疾床位2,000／日；实际保单确认医院原因无法医保仍100%，并接受垫付限制 |

三种升级险**择一**，无需全部叠加。若MSH对关键健康情况除外、目标医院不便直付，而众安或安盛给出更好的书面承保和服务条件，应以实际结果重排。[^msh][^za][^axa]

### 若一般疾病只用普通部：1,451元的定向特需组合

**太保B271元＋众安中高端2026普通版计划二0免赔1,180元＝1,451元／年。** 普通一般医疗0免赔，29项癌症／特定疾病可使用特需，特需床位3,000元／日，相关前后门诊60／60天。特需机构无法医保结算有100%例外；院外医保内药械仍存在独立的未医保60%规则。[^cpic][^za-standard]

这是本次值得保留的低成本方案：相较MSH组合，少付1,745元／年。代价是**一般疾病与未达29项定义的疾病无法使用特需保障**，普通一般单人病房床位只有500元／日，升级层仍一年不保证续保，并有众安的网络预授权要求。29项包含轻度癌症、原位癌，但不能据此推导其范围比120种合同重疾全面。[^za-standard]

如果最终确认“普通病去普通部，只有约定癌症／特疾才去特需”足够，这一组合可以优先于全面特需方案进入核保。若希望诊断阶段和未达疾病定义时也能选特需，则保留前述全面方案。

### 如果决定控制保费：太保E计划三＋全面特需

**690＋16＋207＝913元／年。** 普通部低自付，重大疾病特需0免赔，保留一般病特需但有1万元免赔、床位1,500元／日上限。它是值得比较的经济方案，**不能表述为一般疾病特需也基本不花钱**。[^cpic]

公司团险可能抵扣长期医疗险部分免赔，但必须看实际发生并已报销的合规费用；团险显示的2.5万元保额，不能直接当成2.5万元免赔抵扣额度。离职后是否仍能接受这层自付，应单独评估。

## 7. 下一步只验证三件事

1. **取得承保结论：**对候选如实提供健康告知所需材料，比较标准承保、加费和除外的实际文本。先有核保结果，再定最终购买顺序。
2. **核对具体医院和结算：**按实际意向列出上海、苏州的院区及科室，逐项确认普通／特需、住院／肿瘤门诊、直付／垫付、预授权和无医保结算规则。
3. **确认可接受的剩余自付：**重点是床位超过2,000／2,500／3,000元的差额、药械清单外费用，以及一年期特需未来续投的不确定性，而不是只选最低保费。

目前没有替个人提交投保申请或健康核保。这份比较提供的是报价和核保的候选顺序；最终应记录实际保单版本、特别约定、费用清单与医院服务答复。

## 8. 重疾险目标，留待下一阶段

重疾险希望在满足合同约定的疾病、手术或状态条件后，一次性取得一笔现金，用于休养、家庭生活和收入中断期间的缓冲。**不是所有疾病确诊即赔。** 目标保额、保障期限和具体产品待医疗险讨论后决定，不把费用报销与现金给付混在本轮比较中。
