## 三天怎么走｜周五抵达、周末两日游 {#itinerary}

| 日期 | 核心安排 |
| --- | --- |
| <span id="friday"><strong>10/16 周五</strong></span> | 吴江松陵出发 → 前往金山枫泾／酒店 → 晚餐、入住。若仍需先去御桥会合，再从御桥到枫泾；这段跨城转场单独留时间。 |
| <span id="saturday"><strong>10/17 周六</strong></span> | 早餐后正常入园 → 初级驾驶学校与乐高城市 → 午餐和坐下休息 → 4D 电影、拼搭／一项可接受的乘骑 → 顺路讨糖 → 晚餐、回同一家酒店。 |
| <span id="sunday"><strong>10/18 周日</strong></span> | 退房、行李寄存 → 补喜欢的项目、迷你天地与创意工坊 → 午饭、休息 → 按返程车次取行李离开。第二天以补玩为主，不再重走全园。 |

**建议仍按不午睡、午间坐下休息来安排**；孩子现场困了就调整，不用为了两日票多刷项目。一天先保证 3—4 个感兴趣的体验，再加入演出或讨糖；这是家庭节奏建议，不是预计能玩数量的承诺。

### 从吴江／上海出发，交通重点在金山北 {#transport}

乐园在**上海市金山区枫泾镇乐缤路 999 号**，官方酒店在**乐纷路 188 号**。两条路名不同，打车要选准确目的地。[官方交通指南](https://www.legolandshanghai.cn/guide/traffic)

| 出行方式 | 本次判断 |
| --- | --- |
| **吴江自驾** | 两孩和两晚行李都在一起，值得优先比较；按实际出发地导航，不写固定车程。先确认酒店停车和周日取行李路线。 |
| **高铁＋短途接驳** | 先查能否方便到 **金山北站**；若需经上海虹桥换车，把换乘、候车和带娃步行一起计入。金山北到园区可打车，或查乐园环线。 |
| **上海市区会合后出发** | 若沿用 17:00 御桥会合，需要另查御桥→枫泾路线；原迪士尼的 11 号线路线不能直接用于乐高。 |
| **周日返程** | 优先查金山北→目的地及必要换乘；不要先沿用上海南站返程再倒推。先确定车次，再确定离园时间。 |

官网交通页列**乐园环线（金山北—乐高乐园公交枢纽）首班 08:00、末班 20:00**，并要求以导航应用具体运营信息为准。这个末班信息不是 10/17、10/18 的班次保证；看完节目再出园时，需留走到站点和候车的余量。[官方公交说明](https://www.legolandshanghai.cn/guide/traffic)

**高铁儿童票按年龄判断。** 若仍是妈妈一人带两个未满 6 岁孩子，一名成人最多携带一名免票且不占座儿童；另一个需要儿童优惠票。本次建议两个孩子都买儿童优惠票，各有座位。去回程车次与票价另查。[12306 儿童票规则](https://kyfw.12306.cn/otn/gonggao/saleTicketMeans.html?linktypeid=means5)

| --- | --- |
| 两天门票 | 周六最合适的四人组合＋周日最合适的四人组合；分别核价 |

## 下单与出发前，只落实这些 {#checklist}

1. **门票：**分别选择10/17和10/18，核四人普通票与三种亲子组合的结算价；核是否有适用的两日产品。不要先拿特邀折扣当预算。
2. **酒店：**一间两晚、2成人＋2名4岁儿童，确认装修完成时间、实际床位、两娃早餐、含税总价、取消截止和周日寄存。
3. **交通：**车次、停车、金山北接驳或御桥会合后转场；按车次倒推周日离园，候车缓冲单独留出。
4. **当日 App：**复查花果山冒险关闭状态；查《花果山降魔》、派对和工坊场次，选择一场合适的室内休息。
5. **项目：**现场测高、核年龄及成人陪同；不先为未确认达标或关闭的项目买快速权益。
6. **入园：**带四人购票对应的有效证件原件；核推车尺寸、常温零食和换洗衣物。门票可人工核验，不必为了入园强行选择人脸登记。
