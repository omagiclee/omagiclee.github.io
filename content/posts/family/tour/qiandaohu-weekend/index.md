## 交通：照这个窗口选票

| 哪一段 | 推荐安排 | 预留时间 |
| --- | --- | --- |
| **周六去程** | 苏州南 → 千岛湖，优先直达 | 11—12点出发，13—14点到 |
| 出发候车 | 从家到苏州南站另算 | 提前45分钟到站 |
| 高铁站 → 酒店 | 接站车／打车；四人＋行李 | 出站至入住留60—75分钟 |
| **周日返程** | 千岛湖 → 苏州南 | 争取17点发车、19点到 |
| 酒店 → 高铁站 | 取完行李再出发 | 至少提前2小时离酒店 |
| 想更早抵达 | 查杭州西**同站**中转 | 换乘留30—45分钟 |

**车上约1.5—2小时；表内均为选票目标和规划缓冲。** 具体日期查[12306](https://www.12306.cn/)；预约车辆时说明两张适龄儿童安全座椅需求。

| 两个4岁孩子的高铁票 | 怎么买 |
| --- | --- |
| **推荐：各买一张儿童座票** | 四人都有座位，方便吃饭和休息 |
| 可选：两孩不占座免票 | 每名成人带一名未满6岁儿童；两孩都须申报 |

## 周日：只去黄山尖一个岛

**坐船找小岛 → 缆车登高 → 看群岛全景 → 回岸午饭。**

| 黄山尖短线 | 订前看什么 |
| --- | --- |
| **时间** | 公开产品写9点出发、约2.5小时；**实际周日须确认** |
| 集合点 | 东南湖区旅游码头，提前约30分钟到 |
| 船型 | 可能为18—30座休闲艇或11座快艇；先问清 |
| 缆车 | 页面“平日”含往返；确认周末及两孩是否包含 |
| 返回 | 目标12:30前回岸，留出午饭和返程时间 |
| 儿童饮水 | 该产品列液体携带限制；问能否自带、船上能否提供／购买 |
| 推车 | 台阶与收纳未确认；登岛用小背包，推车留酒店更省事 |

依据：[黄山尖短线产品](https://huodong.ctrip.com/ottd-activity/dest/t62095695.html)。住希尔顿可另问[酒店码头单岛线](https://huodong.ctrip.com/ottd-activity/dest/t34579063.html)（公开时长约2.5小时，班次待确认）。

### 儿童票别混用

| 票种 | 两个孩子怎么处理 |
| --- | --- |
| 普通游船 | 景区介绍列有≤6岁或≤1.2米免门船票；**按所选产品确认** |
| **上述黄山尖短线** | 页面仅写1米以下免票；孩子已满102 cm，须问儿童价 |
| 酒店艇／缆车 | 单独核对，不能套普通游船免票规则 |

[普通游船规则线索](https://you.ctrip.com/sight/chunan2249/135833.html) · **周六日不能套用周五免门票优惠。** [2026年票务政策](https://www.qdhnews.com.cn/news/content/2026-03/25/content_9886217.html)

### 天气差或没合适短线：直接换

| 情况 | 改成什么 | 退房安排 |
| --- | --- | --- |
| **下雨／孩子想休息** | 酒店儿童空间；泳池先确认开放 | 接近12点退房 |
| 想室内逛逛 | 淳安县博物馆，45—90分钟 | 早餐后退房寄存 |

| 想改陆地登高 | 天屿；先确认上山扶梯、下山景交车 | 不与登岛叠加 |
