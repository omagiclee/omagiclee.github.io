现在具身智能公司的数据路线，本质上是三层叠加：公共数据做预训练，自有实战数据做闭环，仿真数据做扩量。开源数据决定模型能否起步，商业数据决定系统能否交付，仿真决定能力能否以可接受成本放大。真正的竞争焦点不是“谁拿到更多公开数据”，而是“谁能持续生产高质量部署数据，并把失败和接管转成训练信号”。

## 核心判断

- 开源数据提供通用视觉语义、语言 grounding 和基础操作先验，是冷启动底座。
- 商业实战数据提供特定硬件、特定任务、特定环境下的真实动作监督，是落地上限。
- 互联网视频和第一视角人类视频通常不包含机器人动作 GT，主要用于 VLM、世界模型和时序先验训练，而不是直接训练低层控制。
- 仿真数据最适合低层控制、重复技能和长尾扰动扩量，但不能替代真实部署闭环。

## 开源数据解决的是“起步”

| 数据类型 | 典型代表 | 主要价值 | 主要边界 |
| --- | --- | --- | --- |
| 开源机器人示范数据 | Open X-Embodiment、DROID、LeRobot | 学习 observation-language-action 对应关系，建立基础 manipulation prior | 覆盖有限，难以反映具体硬件、控制延迟和客户任务分布 |
| 互联网视频与第一视角人类视频 | Web video、Ego4D | 学习视觉语义、任务结构、动作先验和未来状态演化 | 通常没有 joint/action GT，不能直接作为机器人低层监督 |
| 仿真与 synthetic data | Isaac、GR00T 一类路线 | 低成本扩量、覆盖长尾、强化鲁棒性 | 存在 sim-to-real gap，尤其在精细接触、触觉、软体物体上 |

开源数据的作用，不是直接交付一个可用机器人，而是让模型先具备三个基础能力：看懂场景、理解指令、掌握基础操作结构。它能显著降低冷启动成本，但很难覆盖真实业务中的任务分布、系统延迟、安全约束和失败模式。

其中，互联网视频最容易被高估。它更适合训练表征、世界模型和人类操作先验，而不适合直接充当机器人动作监督。真正让模型“接上执行器”的，仍然是机器人示教数据和真实 rollout 数据。

## 商业实战数据决定的是“能不能交付”

对具身公司而言，最有价值的数据通常来自四个环节：

1. 遥操与示教数据：定义可执行动作空间，把模型对齐到具体 embodiment、控制频率和任务接口。
2. 自主 rollout 数据：让机器人自己跑出 on-policy 分布，持续扩大覆盖，而不是永远依赖人工示教。
3. 失败、接管与恢复数据：记录为什么失败、人如何纠正、模型是否学会，这类数据通常比成功样本更稀缺也更值钱。
4. 客户现场部署数据：任务是否成功、耗时多少、是否接管、是否触发安全约束，都天然带结果标签，是最接近真实收益的 ground truth。

这也是为什么真正的数据壁垒不在“公开数据吃得多不多”，而在“有没有现场、有没有遥操系统、能不能把部署过程持续回流为训练数据”。没有真实部署，模型只能学到通用先验；有了真实部署，系统才能学到任务分布、失败模式和交付约束。

从场景看，仓储和制造最容易率先形成数据飞轮，因为任务重复、目标明确、成功定义清楚；家庭和开放环境的数据价值更高，但采集成本、隐私约束和安全要求也明显更重。

## 哪些数据必须真采，哪些更适合仿真

| 必须真采的数据 | 原因 |
| --- | --- |
| 机器人本体上的 state-action 数据 | 只有真实系统才能反映关节限制、控制延迟、执行器噪声和感知误差 |
| 接触、力控、触觉相关数据 | 精细接触最容易受现实误差影响，仿真通常只能近似 |
| 真实任务流中的失败、接管、恢复数据 | 这是商业落地最关键的监督信号，公开数据几乎无法替代 |
| 客户现场的人机协作与安全数据 | 涉及流程约束、节拍、异常处理和真实 KPI，只能在现场获得 |

| 更适合仿真生成的数据 | 价值 |
| --- | --- |
| 步态、平衡、抗扰动、跌倒恢复 | 低层控制依赖海量 trial-and-error，仿真是天然主训练场 |
| 结构化重复技能 | 如抓取、放置、插接、搬运，适合通过参数随机化快速扩量 |
| 长尾扰动和稀有失败场景 | 真机难系统覆盖，仿真可以批量扫参数、做压力测试 |
| 导航、感知、动力学随机化样本 | 适合生成大规模 synthetic data，用于提升鲁棒性和泛化 |

更准确地说，仿真的最大价值不是替代真实数据，而是放大真实数据的单位价值。少量真实示教和系统辨识负责校准，仿真负责扩量和扫长尾，最终再由真实部署闭环完成修边和收敛。这是目前最现实、也最有效的数据路线。

## 结论

今天做具身智能，真正的竞争已经不是“谁能拿到开源数据”，而是“谁能持续拿到高质量闭环实战数据”。开源数据负责冷启动，商业数据负责落地，仿真负责放大。最强的数据壁垒通常来自这条完整链路：

`公共预训练 -> 机器人示教 -> 自主 rollout -> 失败恢复 -> 仿真扩增 -> 部署后训练`

所以，判断一家具身智能公司数据能力的关键，不是看它是否发布了一个大模型，而是看它是否同时具备部署场景接入能力、遥操系统、数据引擎、失败闭环能力，以及把真实数据和仿真数据协同起来的工程能力。
